# Round Table Flyer Finisher

Independent Next.js + Supabase app, ready to configure and deploy to your Vercel account.

**Start with [SETUP.md](SETUP.md).** It covers Supabase SQL, email templates, Vercel environment variables, admin assignment and the live validation steps.

Includes Area 1–18 and RT 1–400 selectors, Area Logos filtering, member uploads, admin moderation, original-logo compositing, activity tags, editable text, coloured strips and JPEG export.

Run `npm ci`, `npm run dev`, `npm test` and `npm run build` from this folder. See `.env.example` for the two public configuration values.
